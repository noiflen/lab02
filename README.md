## 📋 Описание
Работа выполнена с модульной структурой: каждое задание в отдельном файле, но все запускаются из одного главного класса `Main`. Код написан с использованием базовых конструкций (циклы, условия) для максимальной прозрачности логики.

## 📂 Структура проекта
| Файл | Описание |
| :--- | :--- |
| `Main.java` | Главный класс, запускает все задания по очереди |
| `Task1.java` | Задание 1: Методы Collections |
| `PrimesGenerator.java` | Задание 2: Класс-генератор простых чисел |
| `PrimesGeneratorTest.java` | Задание 2: Тестовый класс для вывода чисел |
| `Task3.java` | Задание 3: Множества и сравнение объектов |
| `Task4.java` | Задание 4: Частота слов |
| `Task5.java` | Задание 5: Обмен ключей и значений |

## 🚀 Как запустить
Запустите метод `main` в классе `Main.java`. Он по очереди выполнит все 5 заданий и выведет результаты в консоль.
